# pkanban search

Search card titles and descriptions on every board you can open.

```bash
pkanban search <query> [--board BOARD] [--limit LIMIT]
```

**Arguments**

- `query` (str) — Words to look for. No quotes needed: every word is used.

**Options**

- `--board`, `-b` (int) — Search only this board
- `--limit`, `-n` (int range) _(default: `20`)_ — Most results to show
