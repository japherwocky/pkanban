# pkanban init

Tell this project's AI agents which board to use.

```bash
pkanban init --board BOARD_ID [--file FILE]
```

**Options**

- `--board`, `-b` (int) _(required)_ — The board this project's work is tracked on.
- `--file`, `-f` (str) — Instructions file to write. Default: AGENTS.md, or CLAUDE.md when only that exists.
